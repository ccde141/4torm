# 季风 · 智能体对话

## 季风是什么

季风是你与一名 Agent 持续交流的地方。你可以进行普通对话，也可以让 Agent 读取资料、修改文件、调用工具，或在需要时组织当前会话的工作队。

同一 Agent 可以拥有多段独立会话。消息、执行过程、任务板和当前选择的模型属于各自的会话；Agent 在控制台保存的长期配置与默认工作区则由这些会话共用。

## 开始会话

进入「季风」后，在左侧选择 Agent，再从会话列表打开已有会话，或点击加号创建新会话。会话顶部可以切换本段对话使用的模型，不会改变 Agent 在控制台设置的默认模型。

## 发送图片

你可以通过输入区的附件按钮选择图片，也可以粘贴或拖入图片。发送前可以预览并移除单张图片。回复期间的插话不能附带图片；等本轮结束后，再将图片作为新消息发送。

单条消息最多附带 4 张图片，每张不超过 8 MB，支持 PNG、JPEG、WebP 和 GIF。图片保存在当前会话中，重新打开会话后仍可查看。要让 Agent 理解图片内容，当前所选模型也必须支持图片输入。

## 查看执行过程

Agent 回复时，界面会显示当前的运行状态。模型提供思考内容时，它会与正式回复分开展示；工具调用会形成可展开的记录，便于查看参数、结果和错误。文件修改也会显示改动差异。

思考与执行过程默认显示限高预览。左侧三角可以完全收起或展开该区域，旁侧的「完整高度／限高预览」按钮单独调整显示高度；正式答复显示在过程区域之外。

耗时较长且支持后台运行的命令会返回执行编号。Agent 可以继续其他工作，之后再查看输出、等待结果或终止命令；你也可以在任务板的执行记录中查看和停止它。

## 回复期间补充信息

Agent 正在回复时，你仍可在输入区发送文字补充。消息会尝试进入当前执行；如果本轮恰好结束，就作为下一轮消息。尚未确认送达的内容会保留在界面上，供你核对或继续处理。图片和 `/compact` 指令需等本轮结束后再发送。

## 工作队协作

遇到适合分工的任务，主 Agent 可以在当前会话创建工作队并派工。成员分别处理被交付的部分，主 Agent 负责协调、检查回报和完成最终交付。

会话顶部的工作队入口可以查看成员、派工、成员会话和回报。

## 让 Agent 跨功能区协作

你可以在季风中提出目标，让 Agent 自主选择协作方式、安排分工并跟进执行。也可以直接指定希望使用的功能区。

在控制台点击 Agent 卡片，进入「工具」，启用需要的对流、气旋、信风或潮汐能力并保存。

| 功能区 | Agent 可以完成的协作 |
|---|---|
| **对流** | 创建会议、安排成员与发言顺序、发起讨论，与会议助理私聊，并读取指定轮次的讨论。 |
| **气旋** | 建立工作室、工位和群聊，配置主管、委托主管统筹或直接向工位派工，查看项目履历、公告板和交付。 |
| **信风** | 创建、调整并启动两种模式的工作流，管理循环配置，读取运行记录、交接信封与归档会话，向节点或会议追加信息。暂停点由你放行。 |
| **潮汐** | 创建间隔或每日定时任务，调整、启停或立即运行，并查看记录；结果保存在独立潮汐会话或追加到指定季风会话。 |

例如，你可以这样交代：

> 检查这个项目的代码结构和测试覆盖。建立气旋工作室，让两个工位分别完成检查，完成后在群聊中对齐结论。由你跟进进展，把需要我决定的问题和最终报告交给我。

需要调查、编写文件或执行命令的工作，适合交给各自工位；群聊用于同步目标、讨论分歧和整合结论。

如果希望由工作室主管接手项目统筹，可以补充：

> 为这个工作室配置一名主管，由主管安排工位分工并跟进交付。先确认主管绑定和可用工位，再把项目目标交给它；之后读取主管的回复和派发记录汇报进展。

这些操作需要启用相应的气旋能力；主管、工位和群聊分别承担统筹、执行与讨论，具体见[气旋](./cyclone)。

Agent 可以查看运行状态、等待任务完成、读取结果，再安排下一步。你也可以进入对应功能区，查看工位会话、会议讨论、节点结果或任务运行记录。

## 创建自定义工具

季风 Agent 可以编写并申请注册自定义工具。你在会话中确认注册后，工具会进入全局列表；需要使用时，再到控制台为相应 Agent 启用。

## 管理长会话

对话过长时，可以在回复结束后发送 `/compact`，将当前会话整理成摘要并继续交流。自动压缩的开关、阈值和模型，在控制台的「全局设置 → 会话压缩」中配置。

超长记录会分段整理后合并，界面会显示当前层级和已完成片段。压缩优先直接生成摘要；支持关闭思考的接口会使用该能力，其他接口仍受独立的思考与正文预算限制。

只有完整摘要成功保存后，当前上下文才会替换。暂停、模型错误或软件异常退出都会保留原会话；重新压缩相同内容时会复用已保存的完整片段，不会自动重发中断中的请求。模型、压缩要求或原文变化后重新计算。

自动压缩会保留近期原文，并归档被整理的历史。摘要是继续工作的提要，不代替原始记录。会话列表的 Token 数展示当前有效上下文的输入量，预估性质和来源见悬浮提示。输入包含可用的系统提示词与工具定义，不预测你下一条消息的长度。读取会话，以及编辑、删除或压缩上下文后会重新估算；压缩前的归档原文不重复计入。全新空会话可以显示 `--`。执行中的请求计量与历史累计费用分别保留，预估不会产生模型调用或费用。

右侧任务板属于当前会话，用来记录多步骤工作的目标和进度。你可以查看 Agent 写入的事项，也可以手动新增、修改或删除；同一 Agent 的不同会话不会共用任务板。
