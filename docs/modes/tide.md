# 潮汐 · 自动化任务

潮汐让一名 Agent 按设定间隔或每天固定时间处理一项工作。例如，你可以让它每隔一天检查项目进展，或每天早晨 08:00 写一份简报。任务会在 4torm 后端运行期间按时触发；你不需要一直停留在潮汐页面。每次执行的结果都会留下记录，供你回看。

## 安排任务

在潮汐页面选择 Agent，点击任务列表旁的「+」，填写任务名称、执行内容、触发计划、执行次数和推送目标。页面创建的任务会直接启用，创建动作本身不会立即运行任务。也可以在季风中描述想要的自动化，让 Agent 创建并启用任务；需要先审阅时，可让它只保存未启用的草稿。

- **间隔触发**：例如每隔 5 分钟。首次从启用时计算，后续在本轮结束后重新计时。
- **每天定时**：例如每天 08:00。按运行后端的电脑当前时区执行，不随远程客户端的时区变化；时点已过时，安排下一天。修改时间、重新启用或启动后端都不会补跑已错过的每日时点。

每日计划正常运行时每秒检查一次。若当时该任务仍在执行，不会再启动一轮；长时间休眠后也不会补排已过的每日时点。夏令时导致某个本地时分不存在时跳过当天，重复时分只选择第一次。

任务每次触发时，使用该 Agent 当时在控制台中的模型、工具、技能和执行权限。需要提前检查一次效果时，可以在任务详情中使用「立即运行」；需要阻止后续自动触发时，可以暂停任务。暂停不会中断已经开始的那一轮。

暂停任务并等当前一轮结束后，打开详情中的「编辑任务」，可以调整名称、执行内容、触发计划和执行次数；独立会话还可以调整保留轮数。保存后重新启用，按更新后的计划继续。

需要结束正在执行的一轮时，也可以让季风中止该次潮汐运行，再检查其最终状态。中止不会暂停后续计划，不会把未完成回复写成已完成会话，也不会回滚已经执行的文件操作。结果已开始保存时不再接受中止；如果希望任务完全停下，应先暂停计划，再中止当前一轮。主动中止会记为「已中止」，不计入连续失败次数。

也可以让季风为已有任务更换执行 Agent。任务执行或会话压缩期间不能换绑；独立会话会从新上下文开始，原 Agent 的会话、产物与运行历史继续保留。指定季风会话的任务换绑时，还需明确选择属于新 Agent 的目标会话。

## 决定结果放在哪里

**潮汐独立会话**适合持续巡检或资料整理。任务有自己的会话，下一次运行可以接着之前的内容继续。你可以设置保留轮数，限制当前会话带给模型的历史长度：设为 `1` 时，每轮独立运行并归档，活跃会话随后清空；设为更大的偶数时，达到该轮数后归档较早的一半，保留近期内容。每轮结果仍可从任务的运行历史回看。

同一名池化 Agent 可以同时参与季风、气旋、信风等功能区的工作，独立潮汐任务不会因它在其他地方忙而被阻止。不同的独立潮汐任务分别保存会话和运行记录；同一条任务的前一轮尚未结束时，不会重叠启动下一轮。

这些任务仍共享池中 Agent 的配置、记忆、工作区和工具资源，模型服务的并发限制也会影响实际开始推理的时间。因此，会话与执行记录独立，不代表对同一文件的修改或模型额度彼此隔离。

**接续季风会话**适合把定期结果接到已有对话中。Agent 会读取目标会话的上下文，再把本轮任务内容和最终回复追加进去。工具调用过程不会出现在该季风会话中，但会保存在对应的潮汐运行记录里。如果目标会话当时正在回复，这次潮汐运行会记录失败，不会强行写入或立即重试；这类忙线不会计入连续失败次数。

「保留轮数」控制任务执行后的整轮归档；「压缩会话」用于整理较早上下文，并保留近期原文。查看独立潮汐会话时，点击「压缩会话」即可开始，具体保留方式见[会话压缩](../guide/agents#会话压缩)。

执行或压缩状态会显示在页面上，尚未提交的压缩可以中止，失败或中止后仍使用已保存的内容。压缩完成后，摘要收在「历史摘要」分隔线内，点击可展开；后续消息继续正常显示。追加到季风的内容，在对应的季风会话中整理。

## 让 Agent 管理定时任务

你可以在季风中交代要反复执行的工作、执行间隔或每日时间、负责的 Agent 和结果去向，让 Agent 创建并启用潮汐任务。它可以为自己或控制台中的其他 Agent 安排任务，也可以检查已有任务和运行记录，接续现有安排。

需要调整时，可以让它修改任务内容与执行计划，暂停或重新启用任务，立即运行一次并查看结果，或删除不再需要的任务及其潮汐记录。

例如：

> 每隔 24 小时检查一次这个项目的文档变化，整理变更简报，保存在独立潮汐会话中。先立即运行一次，读取简报让我看看效果。

希望在固定时刻执行时，可以这样交代：

> 每天按运行后端的电脑当前时区，在早晨 08:00 检查项目进展并整理简报。使用每天定时，关闭期间错过的不补跑。创建后告诉我下一次执行时间。

Agent 工具的 `schedule` 对应使用 `every 5m` 或 `daily 08:00`；每天定时使用 24 小时制。

需要把定期结果接到已有讨论中时，也可以指定负责执行的 Agent 的一段季风会话。

在潮汐页面点击该任务，可以查看设置、启用状态和运行记录。

## 让任务自行接续

普通任务每次执行同一份任务内容。开启「自主接续任务」后，Agent 会在本轮结束时提出下一轮要做的事，在你最初设定的目标下继续推进。这种模式使用独立潮汐会话、两轮上下文窗口并持续运行；需要结束时，由你暂停任务。

## 查看和管理运行

任务卡片会显示计划或执行状态、剩余次数、上次运行和下次触发时间。打开任务详情，可以查看执行 Agent、触发计划、推送模式、当前输入量和近期运行历史。数值展示当前有效上下文的输入量，预估性质和来源见悬浮提示；整理、编辑或删除内容后重新计算，不预测下一条消息。全新空会话可以尚无预估；运行历史保留当次实际计量，不用当前预估覆盖过去的费用。

每条运行记录显示结果、时间、耗时和轮数。长回复可以点击「展开完整结果」，工具调用可以展开查看参数和返回内容；有可用会话时，可以进入会话继续查看消息。保留轮数为 `1` 的独立任务每轮都会归档，查看结果应使用运行历史。运行失败会保留原因；连续失败达到三次时，任务会自动暂停，待问题解决后可以重新启用。

新运行记录会保存执行时的 Agent 与归档状态，查看会话时沿用这份记录，不套用任务后来修改的推送模式或保留轮数。旧记录缺少这些信息时会保留查询入口；未保存负责 Agent 的记录仍使用任务当前的 Agent 查询。

4torm 后端关闭时，潮汐不会在后台执行；仅关闭连接独立后端的客户端，不会停止调度。后端重新启动后，每天定时直接安排未来时点；间隔任务沿用保存的计划，已到期时会执行一次，不会把关闭期间错过的每个间隔逐个补跑。
