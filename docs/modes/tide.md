# 潮汐 · 自动化任务

潮汐让一名 Agent 按设定间隔反复处理一项工作。例如，你可以让它每隔一天检查项目进展并写一份简报。任务会在 4torm 运行期间按时触发；你不需要一直停留在潮汐页面。每次执行的结果都会留下记录，供你回看。

## 安排任务

在潮汐页面选择 Agent，再为它设置任务内容、执行间隔和次数。也可以在季风中描述想要的自动化，让 Agent 创建并启用任务；需要先审阅时，可让它只保存未启用的草稿。任务启用后，从创建时开始计算首次触发时间；创建动作本身不会立即运行任务。

任务每次触发时，使用该 Agent 当时在控制台中的模型、工具、技能和执行权限。需要提前检查一次效果时，可以在任务详情中使用「立即运行」；需要阻止后续自动触发时，可以暂停任务。暂停不会中断已经开始的那一轮。

## 决定结果放在哪里

**独立潮汐会话**适合持续巡检或资料整理。任务有自己的会话，下一次运行可以接着之前的内容继续。你可以设置保留轮数，限制当前会话带给模型的历史长度：设为 `1` 时，每轮独立运行并归档；设为更大的偶数时，达到该轮数后归档较早的一半，保留近期内容。

**指定季风会话**适合把定期结果接到已有对话中。Agent 会读取目标会话的上下文，再把本轮任务内容和最终回复追加进去。工具调用过程不会出现在该季风会话中，但会保存在对应的潮汐运行记录里。如果目标会话当时正在回复，这次潮汐运行会记录失败，不会强行写入或立即重试。

查看独立潮汐会话时，点击「压缩会话」即可主动整理。追加到季风的内容，在对应的季风会话中整理。

## 让 Agent 管理定时任务

你可以在季风中交代要反复执行的工作、时间间隔、负责的 Agent 和结果去向，让 Agent 创建并启用潮汐任务。它可以为自己或控制台中的其他 Agent 安排任务，也可以检查已有任务和运行记录，接续现有安排。

需要调整时，可以让它修改任务内容与执行计划，暂停或重新启用任务，立即运行一次并查看结果，或删除不再需要的任务及其潮汐记录。

例如：

> 每隔 24 小时检查一次这个项目的文档变化，整理变更简报，保存在独立潮汐会话中。先立即运行一次，读取简报让我看看效果。

需要把定期结果接到已有讨论中时，也可以指定负责执行的 Agent 的一段季风会话。

在潮汐页面点击该任务，可以查看设置、启用状态和运行记录。

## 让任务自行接续

普通任务每次执行同一份任务内容。开启「自循环」后，Agent 会在本轮结束时提出下一轮要做的事，在你最初设定的目标下继续推进。这种模式使用独立潮汐会话、两轮上下文窗口并持续运行；需要结束时，由你暂停任务。

## 查看和管理运行

任务卡片会显示启用状态、剩余次数、上次运行和下次触发时间。打开任务详情，可以查看近期运行是否完成、Agent 的回复以及相关会话。运行失败会保留原因；连续失败达到三次时，任务会自动暂停，待问题解决后可以重新启用。

![潮汐任务的状态、任务内容与运行历史](/images/tide/task-history.webp)

4torm 关闭时，潮汐不会在后台执行。重新启动后，调度会按保存的任务状态和下次触发时间继续；不会把关闭期间错过的每个触发时点逐个补跑。
