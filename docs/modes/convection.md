# 对流 · 多方会议室

对流让你与多个 Agent 在同一间会议室讨论或推进工作。你发起话题后，参与者按设定顺序依次发言；后发言者可以接续已有的公共讨论。会议室另有一名会议助理，你可以单独与它交流，不必把所有想法放到公共讨论中。

## 创建会议室

先在控制台准备至少两名 Agent，再点击会议列表中的加号创建会议室。创建时会自动选定会议助理和参与者；进入会议后，可以在顶部更换会议助理、增减参与者，并调整发言顺序。成员与顺序的调整从下一轮讨论开始生效。

每间会议室保存自己的公共讨论、会议助理私聊和工作区。更换会议室时，这些内容不会混到另一间会议中。

## 公共讨论

在底部输入话题或要求，参与者会依照顶部的顺序回复。后发言的 Agent 能看到之前的公共记录和本轮前面成员给出的最终回复。参与者的思考过程与工具执行会显示在界面上，供你查看；它们不会作为公共发言传给后续成员。

![会议室中的公共讨论与两位参与者](/images/convection/meeting-room-current.png)

参与者可以使用各自已配置的工具，并在会议室的共同工作区协作。先发言者写下的文件，后续成员可以继续查看和处理。各 Agent 的长期记忆仍归自己所有，不会因同处一场会议而自动共享。

讨论进行时，你仍可输入下一条消息；发送后，它会等待当前轮结束再开始。需要结束当前轮时，可使用停止按钮。

## 与会议助理私聊

点击右侧的会议助理标签，可以展开私聊面板。会议助理会参考公共讨论和你们已有的私聊内容作答；私聊不会进入公共讨论，其他参与者也看不到。会议助理私聊只提供文字回应，不调用工具。

公共讨论与私聊不会同时执行。正在进行其中一种回复时，可以先写好另一处的内容，待当前回复结束后再发送。

## 让 Agent 推进会议

你可以在季风中让 Agent 创建会议室，选择会议助理与参与者、安排发言顺序，并发起讨论；也可以让它接续已有会议。

Agent 可以按轮次读取公共讨论或会议助理私聊，查看正在生成的发言，等待本轮完成，再追加问题或调整下一轮成员，继续推进讨论。

例如：

> 让架构研究员和体验检验员讨论这个项目的首次使用流程，由内容编辑担任会议助理。先收集两人的建议，再请会议助理归纳分歧，围绕尚未解决的问题继续讨论，最后交给我一份修订清单。

Agent 发起的会议会出现在对流会议列表中。进入会议室，可以查看成员的流式发言，也可以直接参与讨论。

## 整理讨论上下文

在公共输入框发送 `/compact`，可以整理公共讨论，保留会议助理私聊。发送 `/reset`，则会归档并清空公共讨论与会议助理私聊。

在会议助理私聊中发送 `/compact` 或 `/reset`，只更新该处的私聊记录。
