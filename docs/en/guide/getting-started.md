# Quick Start

Open 4torm, complete the initial setup below, and start your first Monsoon conversation.

## Complete Initial Setup

1. Open **Provider Management** in the Console. Choose the provider type that matches the service, enter its API URL and key, then fetch models or add one manually. See [Model Providers](./providers).
2. Create an Agent in the Console, choose a model, and set its role prompt, tools, and skills as needed. See [Console and Agent Management](./agents).
3. Open **Monsoon**, choose the Agent, and send a message.

Switch between Chinese and English at the bottom-left of the sidebar. After your first conversation, read [Core Concepts](./concepts) or explore the [five collaboration modes](../modes/chat).
