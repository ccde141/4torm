# 控制台与 Agent 管理

## 控制台是什么

控制台是所有 Agent 的管理入口。在这里创建的 Agent 会长期保留，可以在季风、对流、气旋、信风和潮汐中复用。你配置的是同一个 Agent，而不是某个会话里的临时角色。

每张卡片显示 Agent 的名称、角色、当前状态、最近动向、默认模型和工作区。页面顶部汇总智能体总数、空闲数量和会话数。点击整张卡片，可以查看详情和修改配置。

状态与最近动向来自功能区的实际运行信息。如果某些活动暂时无法读取，卡片会提示信息不完整；模型配置不可用时，也会单独显示相应状态。

![控制台中的示例 Agent 卡片](/images/guide/agent-console-current.png)

## 查看 Agent 详情

点击卡片后，可以在详情窗口左侧切换「概览」「统计」「配置」「提示词」「工具」「技能」和「记忆」。

- **概览**展示当前状态及可关联的近期事项。选择一条事项，可以查看所属功能区、运行状态和可读取的记录；有对应入口时，可以前往原功能区。
- **统计**只计算当前可见、且明确归属这个 Agent 的事项。如果部分功能区暂时无法读取，统计范围会提示不完整。
- **配置、提示词、工具、技能和记忆**用于查看或调整 Agent 的长期设定。修改配置后需要保存才会生效。

![Agent 详情与当前状态](/images/guide/agent-detail-current.png)

## 创建 Agent

点击控制台右上角的「创建智能体」。创建窗口按「基本」「提示词」「工具」「技能」分栏；不必一次设置完所有能力，之后可以从 Agent 卡片进入详情继续修改。

「提示词」页预填通用协作提示词，包含事实核验、工具使用、分工交接和结果反馈等约定。可以按用途修改；它只作为新建时的起点，不会替换已有 Agent 保存的提示词。

![创建 Agent 的基本设置](/images/guide/agent-create-current.png)

- **名称**是 Agent 在各功能区显示的名字。
- **角色**是一句简短的界面标记，不会代替角色提示词。
- **描述**说明这个 Agent 负责什么，方便区分不同成员。
- **默认模型**决定 Agent 通常使用哪个模型。留空时，系统会选用已注册模型列表中的第一个。
- **工作区**留空时，系统会为 Agent 创建独立目录；也可以填写其他路径。
- **执行权限**可选「项目级」或「无限制」。它们约束内置文件工具的路径范围，具体边界见[安全与隔离](../architecture/security)。

头像可以选择最大 20 MB 的图片。保存前会居中裁切并转换为 256px WebP；移除后恢复为名称首字母。头像显示在控制台、季风和对流中；气旋、信风和潮汐仍使用各自的首字母或功能标记。

## 配置工具与技能

「工具」决定 Agent 可以调用哪些能力，「技能」提供完成某类任务时使用的方法和知识。新建 Agent 时，框架内置工具默认启用；自定义工具和 MCP 工具需要明确选择。

在 Agent 详情的「工具」页，框架协作能力按对流、气旋、信风和潮汐分组。你可以整组启用或关闭；气旋和信风还可以逐项选择操作。

Agent 会获得已启用能力的使用说明。可调用的操作由你的选择决定，例如创建协作结构或定时任务、启动执行、查询进度和读取结果。

基础工具、自定义工具和 MCP 工具分别列出，可以按需要选择。修改后点击「保存」生效。

![Agent 工具页中的框架能力分组](/images/guide/agent-configuration-current.png)

新建 Agent 时，已安装的技能默认启用，可以逐项取消。技能说明不会一直占用会话上下文；Agent 在需要时通过 `use_skill` 读取。技能附带的专用工具会随技能加入，不需要在普通工具列表中重复选择。

工具名称旁的警示标记表示它可以写文件、删除内容或执行命令等，不表示每次调用都会再次弹出确认。

## 会话压缩

在侧栏「配置」分组中打开「设置」，找到「会话压缩」。

### 设置自动压缩

开启「自动压缩」后，可以调整以下内容：

| 设置项 | 使用说明 |
|---|---|
| 触发阈值 | 为各类会话分别设置整理历史的时机。单位为 K tokens，填写 `240` 表示 240,000 tokens。 |
| 压缩前部比例 | 选择整理多少较早历史。例如，`2/3` 表示整理较早约三分之二的内容；近期原文保留范围优先于这个比例。 |
| 压缩模型 | 选择「使用当前会话模型」，或选择「使用固定模型」并指定模型。 |
| 测试模型 | 检查所选模型能否生成摘要。 |

点击「保存」后生效，无需重启。

会话达到阈值后，会在下一次模型调用前整理较早的历史。会议使用会议助理的模型和压缩提示词；潮汐任务追加到季风会话时，采用季风会话的触发阈值。

### 近期原文保留

压缩优先保留近期的人类原话和最近对话，近期原文保留预算约为30K tokens。私聊优先参考最近4轮，群聊优先参考最近3轮；单轮内容较长时，其中已完成的回复和工具过程也会整理进摘要。

一轮包含一条人类消息，以及随后 Agent 的回复和工具过程。群聊中的多个 Agent 回复属于同一轮。这里的轮次与潮汐任务的执行次数、保留轮数分别计算。

后续请求使用摘要与保留原文，压缩前的消息和工具记录仍可回看。30K是近期原文的保留预算，最终上下文还包含摘要和本次未整理的内容。

### 主动整理会话

等待当前回复结束后，在相应会话中发送 `/compact`；独立潮汐会话使用任务详情中的「压缩会话」按钮。

整理前的原始记录会归档保留。自动压缩可以在 Agent 连续执行任务期间触发；压缩成功后，Agent 使用摘要和保留原文继续当前任务。

### 查看进度与摘要

压缩期间可以查看状态或中止整理。

新摘要保存成功后才会替换对应历史；此前中止或失败，原内容仍然保留，可以重新发起。

完成后，点击「历史摘要」分隔线查看摘要，压缩前的原始记录仍可回看。

## 修改或删除 Agent

点击 Agent 卡片，在详情窗口切换到相应栏目并保存，就能更新设定。删除入口位于详情窗口底部，需要再次确认。

删除会将 Agent 从列表移除，并删除它在 `data/agents/` 下的专属目录，包括默认工作区、季风会话和记忆。配置在该目录之外的工作区，以及其他功能区单独保存的记录，不会由这个按钮一并清理；这些记录和任务可能仍引用已删除的 Agent。
