# 故障排查

4torm 会尽量保留框架或模型提供商返回的 HTTP 状态码与错误正文。状态码用于判断故障类别，具体原因仍以同一条错误中的完整正文为准。

## HTTP 错误码

| 错误码 | 常见原因 | 首要检查 |
|---|---|---|
| `400` | 请求内容或配置不合法；缺少必要字段；模型不接受当前参数、消息、工具或图片；上下文超过模型上限 | 提供商类型、模型 ID、Provider 参数、上下文与错误正文 |
| `401` | API Key 缺失、无效或已过期 | API Key 与鉴权方式 |
| `403` | Key 无权访问目标模型或资源；本地文件工具拒绝越界路径 | 服务商权限、模型授权与 Agent 执行权限 |
| `404` | API 地址、模型、Agent、会话、任务或其他目标不存在 | 地址与对象是否仍然存在，模型 ID 是否准确 |
| `409` | 当前状态与操作冲突，例如对象正在运行、存在挂起提问、名称重复或任务尚不能删除 | 先结束当前执行或处理界面提示的待办状态 |
| `413` | 请求正文、上传图片或附件超过服务允许的大小 | 文件大小与服务端请求限制 |
| `415` | 文件或请求的媒体类型不受支持 | 文件格式与 Content-Type |
| `429` | 模型提供商触发频率、并发或额度限制 | 账户额度、并发量与请求频率 |
| `500` | 4torm 或目标服务发生内部处理、存储或解析错误 | 完整错误正文与后端日志 |
| `502` | 代理无法连接本地推理服务、MCP Server 或上游接口，或上游返回无效响应 | 服务是否启动、API 地址、端口、代理与网络 |
| `503` | 模型服务暂时不可用、正在加载或过载 | 推理服务状态与当前负载 |
| `504` | 上游服务或网关在规定时间内没有完成请求 | 模型是否仍在运行、网络与网关超时设置 |

Agent 执行链路遇到 `429`、`502` 或 `503` 时最多重试 3 次。最终仍显示这些错误，表示重试期间故障没有恢复。
