# 介绍

4torm 用五个功能区组织同一批长期 Agent。模型、提示词、工具和技能只需配置一次，任务不同，选择的协作方式不同。

## 选择功能区

| 功能区 | 管理对象 | 适合处理 |
|--------|----------|----------|
| 季风 | 对话 | 单 Agent 多轮交流、工具调用与子任务委托 |
| 对流 | 会议室 | 多个 Agent 围绕具体议题依次讨论，由人类主持并提供会议助理私聊 |
| 气旋 | 工作室 | 设置长期工位，支持工位私聊、多个群聊和共享工作区 |
| 信风 | 工作流 | 让多个 Agent 按流程接力、分支或汇合 |
| 潮汐 | 自动化任务 | 按时间间隔触发 Agent 执行任务并滚动归档 |

对流与气旋都支持多 Agent 讨论，但用途不同：**对流用于围绕具体议题组织会议**，**气旋用于让固定工位长期协作**
