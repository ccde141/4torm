# 介绍

4torm 让同一批 Agent 在不同工作场所与你协作。你可以在控制台为 Agent 设置模型、角色、工具和技能，再根据当前工作选择对话、会议、工作室、工作流或定时任务。

## 选择工作场所

| 功能区 | 适合什么工作 |
|---|---|
| **季风 · 对话** | 与 Agent 持续交流、交办工作；需要时由它在当前会话建立工作队。 |
| **对流 · 会议室** | 围绕一个议题，让多名 Agent 按顺序讨论，你也可以单独与会议助理交流。 |
| **气旋 · 工作室** | 为长期项目设置固定工位、共享文件与协作关系，让工位私聊或进入群聊。 |
| **信风 · 工作流** | 把工作排成可重复运行的步骤，让 Agent 接力，并设置人工检查点。 |
| **潮汐 · 自动化任务** | 按时间间隔或每日固定时间唤起 Agent 工作，把结果保存在独立会话或指定的季风会话。 |

如果只是开始一段交流，从季风进入即可。需要围绕议题让多人讨论，可以用对流；需要一组长期分工的协作者，则用气旋。信风适合预先安排交接顺序，潮汐适合让工作按时间重复发生。

第一次使用可从[快速开始](./getting-started)完成配置，再阅读[核心概念](./concepts)。
