# 核心概念

在 4torm 中，Agent 是长期保留的协作者；季风会话、对流会议室、气旋工位、信风工作流和潮汐任务，是它参与工作的不同场所。理解“谁在工作”“在哪里工作”“能使用什么能力”，就能分清哪些信息会延续，哪些只属于当前任务。

## Agent 与工作场所

控制台可以创建 Agent，并为它设置默认模型、角色提示词、工具、技能、记忆和工作区。此 Agent 可以进入多个功能区，不需要为每次任务重新创建。

各类工作场所会保存自己的内容。例如，同一 Agent 的两段季风会话互不混合；气旋工位保留自己的私聊；对流会议室保存公共讨论；信风保存工作流和运行结果。更换工作场所，不等于把前一个场所的完整对话带过去。需要另一处工作的背景时，应在新场所提供，或让 Agent 读取它能够访问的记录。

工作场所还可能给 Agent 增加当前任务的职责或共享目录。气旋工位可以设置自己的角色要求，会议室和工作流也有各自的工作区；这些设置不会改写控制台中的 Agent 基础配置。

季风中的工作队成员由主 Agent 为当前会话创建，不会出现在控制台的 Agent 列表中。成员有独立的对话上下文，可以继续接收派工；主 Agent 需要向成员说明任务背景，并检查、整合其回报。

## 工具、技能与 MCP

**工具**是 Agent 读取资料、修改文件、执行命令和开展协作的入口。你可以在控制台为 Agent 选择要启用的工具。

**技能用于**保存可重复使用的知识和工作方法。你可以在控制台为 Agent 启用技能；Agent 需要时再读取技能说明，不必在每次对话中加载全部内容。技能也可以附带专用工具。技能既可以由你创建，也可以由 Agent 自主注册。

**MCP** 用于接入外部工具服务。连接服务后，可以在控制台为 Agent 选择其中的工具。Agent 调用这些工具时，实际可执行的操作取决于外部服务提供的能力及其配置。

## 工作区与执行权限

Agent 有自己的默认工作区；会议室、工作室和工作流也可以提供共享工作区。向 Agent 指定文件时，最好说明文件属于哪个工作区，避免同名文件造成误解。

执行权限分为「项目级」和「无限制」。「项目级」允许内置文件工具访问 4torm 项目及当前工作区；「无限制」允许它们访问其他路径。框架管理的数据仍需通过对应功能入口修改。这项设置只约束内置文件工具；命令、自定义工具和 MCP 工具按各自的能力运行。

## 活动记录与记忆

控制台的 Agent 卡片和详情可以帮你找到近期事项，完整内容仍在所属功能区。较早的事项不一定显示在当前会话里；需要时，你可以告诉 Agent 事项和大致时间，让它检索已保存的记录。

**长期记忆**属于 Agent，用于保留跨任务仍有价值的偏好、约定和经验。它不是完整的会话记录；对话中出现过的信息不会因此自动写入记忆。不同 Agent 的记忆各自独立。

启动一项工作、看到工具返回成功，或收到成员回报，都不代表最终目标已经完成。需要确认结果时，可以查看所属功能区的运行状态与实际产物；仍在执行的工作，也可以在那里继续观察。
