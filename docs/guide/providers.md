# 模型提供商

模型提供商决定 4torm 从哪里调用模型。进入控制台的「提供商管理」，可以添加 OpenAI Compatible 或 Anthropic Messages 接口，并将同一提供商下的多个模型加入 4torm

## 添加提供商

点击「添加提供商」后，可以选择已有预设，也可以创建空白配置

每个提供商需要填写：

- **提供商名称**：用于模型列表中的识别
- **API 地址**：服务商提供的接口地址
- **API Key**：调用接口使用的密钥，不需要时可以留空

保存地址和 Key 后，点击「获取模型列表」即可读取该服务公开的模型。勾选需要使用的模型并确认，它们便会进入 Agent 的模型选择列表

部分服务不提供模型列表接口，或只返回部分模型。此时可以直接填写官方模型名称并手动添加

## 接口协议

4torm 支持两种接口协议：

- **OpenAI Compatible**：适用于 OpenAI、大多数国内模型服务、聚合平台和本地推理服务
- **Anthropic Messages**：适用于 Anthropic 官方接口及兼容该协议的服务

接口协议默认使用「自动识别」。如果地址经过代理、网关改写，或者自动判断与实际接口不符，可以在高级选项中手动指定

非标准服务需要额外鉴权字段时，可以在「自定义请求头」中填写 JSON，例如：

```json
{
  "x-api-key": "sk-xxx"
}
```

自定义请求头会随该提供商的模型请求一并发送，其中可能包含密钥，不应提交到公开仓库

## 模型配置

同一个提供商下的不同模型可能采用不同的参数约定。一般保持「自动」即可，4torm 会结合接口地址和模型名称整理请求参数

自动判断不正确时，可以为单个模型选择对应配置。目前提供通用 OpenAI、Kimi、DeepSeek、智谱 GLM 推理、通义 Qwen 推理、OpenRouter、MiniMax 和硅基流动推理等选项

这项设置只调整当前模型的请求方式，不会改变提供商下的其他模型

## 图片理解

模型列表中的「图片理解」检测用于确认当前接口是否接受图片输入。检测通过后，可以在季风会话中向该模型发送图片

检测结果只代表该接口完成了本次测试。模型是否能够稳定理解图片、支持哪些格式以及可处理的图片大小，仍取决于模型和服务商本身

检测失败也不一定表示模型完全没有视觉能力。代理服务、访问限制或供应商临时错误都可能影响结果，应结合服务商文档和实际对话判断

## 配置保存位置

提供商配置保存在 `data/providers.json`，其中包含 API 地址、API Key、已启用模型和相关模型配置

该文件默认不会进入 Git，但仍应作为含有密钥的个人配置妥善保管
