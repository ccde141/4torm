# 模型提供商

模型提供商决定 4torm 调用哪个服务，以及如何整理上下文、生成参数、思考内容和工具消息。新建配置时应选择与实际服务一致的**提供商类型**；这个显式身份决定请求适配器，不依赖 API 地址或模型名称猜测。

## 添加提供商

进入控制台的「提供商管理」，点击「添加提供商」并选择预设。当前预设覆盖的常用类型包括：

- **通用兼容接口**：OpenAI Compatible，可用于其他兼容 OpenAI Chat Completions 的服务
- **云端提供商**：DeepSeek、Kimi、Alibaba Cloud Model Studio（阿里云百炼）、Zhipu AI（智谱 AI）、MiniMax 等
- **本地推理框架**：LM Studio、llama.cpp、Ollama、vLLM 等

创建后可以编辑名称、API 地址和 API Key。无需密钥的本地服务可将 Key 留空。

点击「获取模型列表」会读取服务公开的模型。部分服务不提供该接口，或只返回部分模型；此时使用服务端的准确模型 ID 手动添加即可。

## 模型级配置与能力检测

模型行中的配置选择保留给旧配置兼容和少数模型级例外。使用带显式类型的新预设时通常保持「自动」，让提供商身份选择适配器。

「图片理解」检测只确认当前接口是否接受一次测试图片。通过后，可以在季风会话中向该模型发送图片；稳定理解能力、格式和大小限制仍由模型与服务商决定。检测失败也不一定表示模型没有视觉能力，鉴权、代理和临时服务错误都会影响结果。

## 配置保存位置

提供商配置保存在 `data/providers.json`，包含 API 地址、API Key、已启用模型、Provider 参数、自定义字段及能力检测结果。
