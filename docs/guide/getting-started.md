# 快速开始

打开 4torm 后，按以下步骤完成首次配置，并开始第一段季风对话。

## 完成首次配置

1. 打开控制台的「提供商管理」，选择与实际服务一致的提供商类型，填写 API 地址和密钥，再获取模型列表或手动添加模型。详见[模型提供商](./providers)。
2. 在控制台创建 Agent，选择模型，并按需要填写角色提示词、检查工具与技能。详见[控制台与 Agent 管理](./agents)。
3. 打开「季风」，选择这个 Agent，发送一条消息。

侧栏左下角可以切换中文与英文。完成首次对话后，可以阅读[核心概念](./concepts)，或进入[五种协作模式](../modes/chat)了解其他工作方式。
